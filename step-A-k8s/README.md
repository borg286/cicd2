# Talos + Longhorn Kubernetes Cluster

## 🎯 Goal
Provision a **Talos** based Kubernetes cluster and install **Longhorn** storage.  The repo provides two pathways:

1. **Quick‑start with k3d** – spin up a lightweight dev cluster using the existing `registries.yaml`.
2. **Production‑ready Talos via Terraform** – create a real Talos node, apply the `controlplane-patch.yaml` (adds Longhorn bind mounts), and deploy Longhorn with Helm.

---

## 📦 Prerequisites
| Tool | Minimum Version |
|------|-----------------|
| Terraform | 1.5 |
| k3d | 5.6 |
| talosctl | 1.7 |
| kubectl | 1.28 |
| Docker | 24 |

- Ensure `${HOME}/.kube/config` is writable – Terraform will use it after `talosctl kubeconfig`.
- Add your SSH key to the Talos node or configure the client certificates referenced in `step-A-k8s/main.tf`.

---

## 1️⃣ Option 1 – k3d Quick Start (dev/CI)
```bash
# Create a k3d cluster with a custom registry (registries.yaml is in this folder)
mkdir -p ~/.k3d && cp registries.yaml ~/.k3d/registries.yaml
k3d cluster create talos-demo \
  --servers 1 \
  --agents 2 \
  --image rancher/k3s:v1.30.2-k3s1 \
  --registry-create "myregistry.local:5000"

# Apply the registries configuration to the cluster
kubectl apply -f registries.yaml

# Install Longhorn via Helm (uses the bundled values file)
helm repo add longhorn https://charts.longhorn.io
helm repo update
helm install longhorn longhorn/longhorn \
  --namespace longhorn-system \
  --create-namespace \
  -f longhorn-values.yaml
```
> **Tip:** The `registries.yaml` mirrors the registry configuration used by Talos, so container images pulled by the Talos control‑plane are cached locally.

---

## 2️⃣ Option 2 – Talos via Terraform (bare‑metal / VM)
```bash
# Initialise and apply the Terraform configuration
cd step-A-k8s
terraform init
terraform apply
```
The Terraform run will:
1. **Bootstrap** the Talos control‑plane node (see `main.tf`).
2. **Patch** the control‑plane machine configuration with `controlplane-patch.yaml` – this adds a bind‑mount at `/var/lib/longhorn` required by Longhorn.
3. **Generate** a kubeconfig (`talosctl kubeconfig`) that Terraform’s `kubernetes` provider consumes.
4. **Deploy** the Longhorn manifests (`longhorn-namespace.yaml`, `longhorn-storageclass.yaml`) and install the Longhorn Helm chart using `longhorn-values.yaml`.

### Verify the cluster
```bash
# Pull the kubeconfig generated by talosctl (Terraform does this automatically)
export KUBECONFIG=$(pwd)/kubeconfig.yaml
kubectl get nodes
kubectl get pods -n longhorn-system
```
You should see the Longhorn manager pods in a `Running` state.

---

## 🧹 Cleanup
### k3d
```bash
k3d cluster delete talos-demo
```
### Terraform (Talos)
```bash
terraform destroy
```
This will de‑provision the Talos node and remove all Longhorn resources.
